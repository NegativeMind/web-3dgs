🧪 CDN配信テスト

このページは、jsDelivr から配信されるウィジェットの動作確認用です。

使用バージョン: main（main ブランチの最新ビルドを配信）

CDN URL: https://cdn.jsdelivr.net/gh/NegativeMind/web-3dgs@main/dist/3dgs-viewer.js

確認項目：
  • <splat-viewer> Custom Element が登録・描画されるか / クリックでポインターロックが有効になるか
  • マウスドラッグで回転・ズーム（Object）/ WASD 移動・マウス視点変更（Immersive）ができるか
  • ロード中インジケーターが表示されるか
  • ResizeObserver によるキャンバスリサイズが機能するか
  • F12 → Console でエラーや初期化ログを確認。CDN からのファイル取得は Network タブで確認
